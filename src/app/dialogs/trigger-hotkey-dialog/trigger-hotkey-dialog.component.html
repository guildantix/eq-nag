Edit Trigger Hotkey

To create a hotkey, enter up to 5 text lines for the commands.

You may use interpolation with {{'{{Your Character Name}}'}}. When using interpolation, the user will be asked to enter values for each variable when they generate a hotkey. Use descriptive names so that the user intuitively knows what to put in each value.

Command

When the "Command" option is enabled, the hotkey will consist of a single line.

When the user executes this hotkey, the line will be copied to the users clipboard without the /hot "Name" command that generates a hotkey.
