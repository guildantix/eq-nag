# Trigger profiles and character triggers

Each character can have its own set of triggers turned on or off. A trigger profile saves that set, so you can give it to another character in one click.

Turning a trigger off for one character does not delete it. Your other characters keep using it.

## Turn triggers on and off for one character

1. Click the **Characters** tab.
2. Click the character's name.
3. Click the **Triggers** tab.

You will see the **Character Triggers** list on the right, with your folders and triggers.

![A character's Triggers tab with the Profile box on the left and the Character Triggers list on the right]({{ '/assets/images/trigger-profiles/character-triggers-tab.png' | relative_url }})

4. Click a folder's arrow to open it.
5. Click a trigger's name, or its box, to turn it off or on for this character.

A green box means the trigger is on. A red box with an X means it is off for this character.

To change a whole folder at once, click the box next to the folder. A yellow box means some triggers in the folder are on and some are off.

Nag saves each change as you make it.

{: .note }
The **Triggers** tab here is only for this character. To turn a trigger off for every character, see [Disabling specific triggers]({{ '/guides/disabling-triggers' | relative_url }}).

## Turn off new triggers by default

Under **Profile**, tick **Disable new triggers by default**. After that, triggers you create or install from the library or Quick Share start out turned off for this character. You turn on the ones you want.

## Save a profile

A profile is a saved list of which triggers are on and off. It also remembers the **Disable new triggers by default** box.

1. Set up one character the way you want, as described above.
2. On its **Triggers** tab, click **Create New Profile**.
3. Type a name in **Profile Name**, such as `Raid triggers`.
4. Click **OK**.

You will see **Profile added!** at the bottom of the window. The new profile is picked for this character.

## Use a profile on another character

This is the quickest way to set up an alt like your main.

1. Click the **Characters** tab, then click the alt's name.
2. Click the **Triggers** tab.
3. Open the list under **Profile** and pick your profile.

You will see the triggers in **Character Triggers** change at once. Nag does not ask first. The alt's own choices are replaced by the profile's.

If you pick **None**, the character keeps its current triggers and stops following a profile.

## Change a profile later

A profile is a copy. When you turn triggers on or off for a character, the profile does not change.

Use the buttons under **Profile**. They only show when the character has a profile picked.

| Button | What it does |
| --- | --- |
| **Reapply Profile** | Throws away this character's on and off choices and loads the profile again. Use it when you changed things by accident, or to pull in a profile that you updated from another character. Nag asks you to confirm. |
| **Update "Name" Profile** | Saves this character's on and off choices into the profile. Every other character that uses the same profile gets those choices too, and their own choices are replaced. Nag asks you to confirm. |

{: .warning }
**Update** changes every character that uses the profile. If only one character should differ, create a new profile for it instead.

## Delete a profile

1. Open the list under **Profile**.
2. Click the red **X** next to the profile's name.
3. Click **Yes**.

You will see **Profile deleted!**. Characters that used it keep their triggers as they are. They just stop following a profile.
